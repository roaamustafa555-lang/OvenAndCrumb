# Oven & Crumb

Web application built with PHP and MySQL (designed to run on a local server environment such as XAMPP / AppServ).

## Overview
A web project for **Oven & Crumb** featuring authentication and core application workflows.

## Tech Stack
- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript
- **Local Environment:** Localhost (XAMPP / AppServ)

## How to Run Locally
1. Clone or download this repository.
2. Move the project folder into your local server root directory (e.g., `htdocs` in XAMPP or `www` in AppServ).
3. Start the Apache and MySQL services.
4. Import the SQL database file (if included) via `phpMyAdmin`.
5. Open the project in your browser via `http://localhost/...`.
